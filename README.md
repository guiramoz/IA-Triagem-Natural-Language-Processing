# Sistema Inteligente de Triagem de Chamados

## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante o curso de **Programação em IA Generativa** do SENAI. O sistema utiliza conceitos de **Processamento de Linguagem Natural (PLN)** para interpretar solicitações enviadas pelos usuários e realizar a triagem automática de chamados de suporte técnico.

A proposta do projeto é simular um ambiente de atendimento, onde a inteligência artificial analisa o problema descrito pelo usuário e o direciona automaticamente para a equipe responsável, tornando o processo mais rápido e eficiente.

## 🚀 Funcionalidades

* Recebimento de solicitações de suporte técnico.
* Interpretação das mensagens utilizando Processamento de Linguagem Natural (PLN).
* Identificação automática do tipo de problema informado.
* Classificação dos chamados por categoria.
* Direcionamento automático para a equipe responsável.
* Simulação de um sistema inteligente de atendimento.

## 🛠️ Tecnologias Utilizadas

* Python
* Processamento de Linguagem Natural (PLN)
* Inteligência Artificial Generativa

## ⚙️ Funcionamento

1. O usuário descreve o problema encontrado.
2. O sistema analisa a mensagem utilizando técnicas de PLN.
3. As palavras-chave e o contexto são interpretados pela inteligência artificial.
4. O chamado é classificado de acordo com o tipo de problema identificado.
5. O sistema encaminha automaticamente a solicitação para a equipe responsável pelo atendimento.

## 🎯 Objetivo

Este projeto possui finalidade acadêmica e tem como objetivo aplicar conceitos de Inteligência Artificial Generativa e Processamento de Linguagem Natural para automatizar a triagem de chamados de suporte técnico, demonstrando como técnicas de IA podem otimizar processos de atendimento e aumentar a eficiência na classificação de solicitações.
